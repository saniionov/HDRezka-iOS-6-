# **HDRezka**

HDRezka — нативное iOS-приложение на Objective-C для просмотра и загрузки фильмов и сериалов с сайта HDRezka на устройствах под управлением iOS 6\.

Проект создан как личная инициатива с использованием помощи Gemini и ChatGPT. Основная разработка завершена. Исходный код публикуется для ознакомления, изучения архитектуры и возможного дальнейшего развития проекта.

## **Возможности**

* Просмотр фильмов и сериалов во встроенном видеопроигрывателе.  
* История просмотров и избранное.  
* Выбор сезона, серии и озвучки.  
* Загрузка видео, в том числе в фоновом режиме.  
* Создание M3U-плейлистов для фильмов, отдельных серий и сезонов.  
* Локальное хранение данных и кэширование изображений.  
* Два режима авторизации: через персональное зеркало с учётными данными и через публичное зеркало с дополнительной настройкой окружения.

## **Технологии**

* Objective-C  
* UIKit  
* SQLite  
* UIWebView  
* Xcode 4.6.3  
* iOS SDK 6.1

## **Совместимость и сборка**

Проект предназначен для старых устройств Apple под управлением iOS 6\.

Разработка и тестирование выполнялись с использованием Xcode 4.6.3 на iPhone 4S и iPad 2\.

Для сборки использовались стандартные средства Xcode. Сторонние библиотеки, необходимые непосредственно для сборки проекта, не использовались.

Для воспроизведения исходного окружения разработки может потребоваться совместимая версия macOS, Xcode и iOS SDK.

## **Настройка**

Описание возможностей приложения и инструкции по настройке находятся в файле `WelcomeText.txt`.

В режиме публичного зеркала могут потребоваться дополнительная настройка сети, прокси или VPN, а также Web Port. Необходимость этих компонентов зависит от используемого зеркала и условий доступа.

## **Ограничения**

Работа приложения зависит от доступности внешнего сайта, его API, механизмов авторизации, защиты от автоматизированных запросов и форматов видеопотоков.

Изменения на стороне сайта, ограничения сети и устаревшие компоненты iOS могут приводить к частичной или полной потере работоспособности. Совместимость с современными версиями сайта не гарантируется.

Проект предназначен для технического ознакомления и экспериментов с разработкой под устаревшие версии iOS.
